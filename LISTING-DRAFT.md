# BlindBench — launch copy draft

## Short description
Compare two AI model or prompt outputs on the same test cases. Judge them blind, record why, and export a clean evaluation report. No API key, account, install, or data upload.

## Who it is for
- Students comparing prompts or model versions in a project
- Builders evaluating a small RAG or assistant demo
- Instructors teaching human evaluation and error analysis

## What it does
- Shows two answers side by side and randomizes which side is labeled A or B per case
- Records preference, ties, cases where both answers fail, and optional rationale
- Imports CSV test cases and exports a JSON report
- Keeps the session in the local browser; works offline

## What it does not claim
BlindBench does not call models, automatically grade answers, establish statistical significance, or rank models universally. It records one evaluator's judgment on the test set provided.
